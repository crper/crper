## 🚀 精选项目

### AI 工作流

- 🧠 [agent-skills](https://github.com/crper/agent-skills) — 沉淀 Codex、OpenClaw 和自动化工作流里的可复用技能
- 📚 [knowledge-chatbox](https://github.com/crper/knowledge-chatbox) — 本地优先的知识工作台：入库、检索问答、来源回看、单机部署
- 🖼️ [py-image-compress-mcp](https://github.com/crper/py-image-compress-mcp) — 为 AI Agent 提供本地图片压缩、格式转换与批量处理的 MCP 工具

### 浏览器扩展

- 🧪 [参数工坊 · QueryCraft](https://chromewebstore.google.com/detail/pnmnfenconpbfomddfhibbcnncmopgnb) — URL 参数编辑工具，支持解析、排序和二维码生成
- 🧮 [股票收益计算器](https://chromewebstore.google.com/detail/moojoeabbjcccmmneljlcdlhediahfbe) — 连板收益、回本涨幅、定投等常用计算
- 🛍️ [小店经营盘](https://chromewebstore.google.com/detail/glehokfhfgiodnfhefeljndfbaijljlg) — 面向小店经营场景的浏览器辅助工具
- ♻️ [Auto Refresh](https://chromewebstore.google.com/detail/auto-refresh/npeboaflpngjenagipdkcepihphchcig) — 定时自动刷新网页，支持 URL 规则匹配
- 🔳 [wxt-chrome-qrcode](https://github.com/crper/wxt-chrome-qrcode) — 基于 WXT 的二维码扩展，支持样式调整与多格式导出

### 桌面与在线工具

- 📱 [tqrx](https://github.com/crper/tqrx) — 终端优先的二维码工具，支持 CLI / TUI、实时预览、PNG / SVG 导出
- 🔄 [py-local-git-pull](https://github.com/crper/py-local-git-pull) — 纯 CLI 的 Git 任务控制台，多仓库扫描、同步、诊断
- 🌍 [Time Shift](https://crper.github.io/next-time-shift/) — 时差换算与时间偏移（[Repo](https://github.com/crper/next-time-shift)）
- 📈 [Stock Return Calc](https://crper.github.io/next-stock-return-calc/) — 股票收益与回本测算（[Repo](https://github.com/crper/next-stock-return-calc)）
- 💹 [Simple Compound](https://crper.github.io/next-simple-compound/) — 复利收益估算（[Repo](https://github.com/crper/next-simple-compound)）
- 🔷 [next-css-polygon-editor](https://crper.github.io/next-css-polygon-editor/) — 可视化编辑 CSS `clip-path` 多边形（[Repo](https://github.com/crper/next-css-polygon-editor)）
- 🖥️ [Tauri-QrCode-BarCode](https://github.com/crper/Tauri-QrCode-BarCode) — Tauri + Vue 3 离线二维码/条码生成器

### 模板与脚手架

- ✨ [next-modern-starter](https://github.com/crper/next-modern-starter) — Next.js 15 + React 19 + Tailwind CSS v4 极简启动模板
- 🧩 [vscode-webview-vite-vue-boilerplate](https://github.com/crper/vscode-webview-vite-vue-boilerplate) — VS Code Webview 模板，集成 Vite、Vue 3、TypeScript
- 📦 [rollup-typescript-lib-boilerplate](https://github.com/crper/rollup-typescript-lib-boilerplate) — TypeScript 库模板，集成 Rollup、Vitest、release-it

### npm 工具库

- 🧱 [placefill](https://github.com/crper/placefill) — 轻量占位符填充库，支持 `string / object / array` 深度模板填充
- 🎯 [tiny-event-intercept](https://github.com/crper/tiny-event-intercept) — 零依赖的条件事件拦截工具，兼容浏览器 API 和 SSR
- ⚡ [fast-map-cache](https://github.com/crper/fast-map-cache) — 高性能 LRU 缓存，支持可选 TTL
- 💤 [idle-resource-loader](https://github.com/crper/idle-resource-loader) — 利用浏览器空闲时间做资源预加载

### 其他

- ☁️ [action-wttr-fetch-city](https://github.com/crper/action-wttr-fetch-city) — 用 GitHub Actions 抓天气并生成分享图片
- 🌿 [vsc-git-branch-warning](https://github.com/crper/vsc-git-branch-warning) — VS Code 敏感分支提醒扩展
- ⌨️ [Visual-Studio-Code-CNKEYMAP](https://github.com/crper/Visual-Studio-Code-CNKEYMAP) — VS Code 快捷键中文映射
- 🐳 [yapi-docker](https://github.com/crper/yapi-docker) — 用 Docker 快速拉起 YApi
